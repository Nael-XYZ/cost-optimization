# Cost Optimization 💰

Cloud cost optimization toolkit for AWS with FinOps best practices.

## Features

- **Rightsizing**: EC2/RDS rightsize recommendations
- **Reserved Instances**: Savings calculator
- **Spot Fleet**: Automated spot management
- **Budget Alerts**: Slack/email notifications

## Savings

| Strategy | Typical Savings |
|----------|----------------|
| Rightsizing | 30-40% |
| Reserved Instances | 40-60% |
| Spot (for batch) | 60-90% |
| S3 Lifecycle | 40-70% |
